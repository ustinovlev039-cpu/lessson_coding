# ПИТОН-90

Браузерная игра для изучения основ Python в атмосфере компьютеров 90-х. 20 миссий по пяти главам: вывод, переменные, условия, циклы и функции. Код действительно выполняется в Python через [Pyodide](https://pyodide.org/) внутри Web Worker. Решения проверяются заданиями, прогресс и черновики хранятся в localStorage.

## Запуск локально

Откройте папку через статический сервер, например:

```sh
python3 -m http.server 8000
```

Затем перейдите на `http://localhost:8000`. Для первой загрузки Python нужен интернет: Pyodide загружается с jsDelivr. После первой загрузки вкладки код выполняется локально в браузере. Зависимостей для сборки нет.

## GitHub Pages

Файлы уже находятся в корне репозитория, а `.github/workflows/deploy.yml` публикует сайт при каждом push в `main`.

Для первого запуска владелец репозитория должен открыть [Settings → Pages](https://github.com/ustinovlev039-cpu/lessson_coding/settings/pages) и выбрать **GitHub Actions** в поле **Source**. Затем на вкладке [Actions](https://github.com/ustinovlev039-cpu/lessson_coding/actions/workflows/deploy.yml) запустить workflow кнопкой **Run workflow**. После успешной публикации сайт будет доступен по адресу `https://ustinovlev039-cpu.github.io/lessson_coding/`.

Все пути к файлам относительные, поэтому сайт работает в подпапке репозитория.

## Устройство

- `index.html` — интерфейс игры.
- `style.css` — адаптивный стиль.
- `levels.js` — миссии и проверки.
- `app.js` — навигация, прогресс, редактор и игровой цикл.
- `python-worker.js` — выполнение Python с ограничением времени.

Проект не требует аккаунта и не отправляет код на собственный сервер. Для доступности CDN в игровой среде должен быть открыт `cdn.jsdelivr.net`.
